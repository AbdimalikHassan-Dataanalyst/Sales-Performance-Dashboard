# Sales Performance Dashboard

## Project Overview
This project presents an interactive sales dashboard summarizing profit, units sold, sales count, monthly sales trends, product performance, and customer-level unit sales.

## Problem Statement
The dashboard is designed to help a business owner or sales team review overall sales performance, identify the products and customers contributing the most units sold, and monitor monthly changes.

## Data
The dashboard displays sales-related fields including:
- Product name
- Customer
- Units sold
- Total purchased
- Profit
